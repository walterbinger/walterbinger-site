# Construction Archive

This directory preserves **historical build receipts, design context, handoffs, rejected drafts, and verification records** for WalterBinger.com.

It is intentionally not the recruiter-facing entry point and should not be read as the current product specification.

For the current public context, start with:

- the repository [README](../README.md)
- the live portfolio at [walterbinger.com](https://walterbinger.com)
- the deployed Living Map beneath the professional homepage at [walterbinger.com/universe/](https://walterbinger.com/universe/)

## How to read this archive

Older files may contain superseded branch names, local paths, agent handoffs, prototype terminology, or construction assumptions that were correct only at that point in the build.

They remain here for provenance and verification—not because every note is still active canon.

The production boundary is simple: the approved professional homepage remains the front door, and the Living Map lives underneath it. Current implementation details should be verified against the live repository state rather than inferred from an older handoff or draft.
