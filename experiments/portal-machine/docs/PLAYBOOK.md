## 1. THE PRODUCT — WHAT VISITORS EXPERIENCE
A credible professional homepage reveals, inside its existing Universe threshold, an unnamed and slightly alarming inventor's machine. A charming ivory PROTOTYPE / CAUTION — EXPERIMENTAL curtain drops under gravity when visitors pull a cord. An EXPOSED mechanical ON/OFF knife switch powers it. The visitor explores a continuous two-dimensional resonance field with a joystick, chooses musical timbre/register, injects harmonic partials through colored physical buttons, and watches genuinely calculated standing-wave structures drive dancing particles and a volumetric projection. They can capture interesting moving field states, combine them, and voluntarily TRANSMIT through the assembled atlas into the Living Universe.
The gateway on the right remains a direct, obvious optional bypass. An easy, fast path is legitimate; a long play session is also legitimate. No timing puzzles; no mystery password; no automatic transport. The public-facing machine has no product/brand name. Internal "WALTron" and version numbers are engineering identifiers only.
Metaphor: a cosmic claw machine for fishing structure out of sound. Outside: credible, engineered brass / patina / ceramics / wooden mount / silver instruments / ink crosshatching. Inside: mysterious dimensional maps and cymatic topographies. Da Vinci drawing discipline + used retro-industrial hardware + futuristic scientific display; homage to moods, not reproduction of film designs.

## 4. ASSEMBLY — ONE PHYSICAL MACHINE, NOT UNCONNECTED COMPONENTS
Make a single ORTHOGRAPHIC MASTER ASSEMBLY first: one desktop front view, one three-quarter view, one silhouette, one cable/power/signal routing schematic, and a mobile/reflow variant. Freeze baseline camera, dimensions, scale, light direction, material palette, z-order and sockets.
Named components:

Connections before detailing:
power_switch.output → power_bus.input → generator.power → tubes.power → projector.power;
joystick.xy → signal_generator.exciter_a/exciter_b;
generator.wavefield → projector.field;
harmonic_injectors.ratios → generator.partials;
capture_bank.states ← generator.snapshot;
transmit_control.trigger → transit_controller.activate, but ONLY after deliberately pressed.
Every cable has two endpoints and a functional type (power, signal, pneumatic, decorative). Decorative routes cannot masquerade as unconnected power. Include physical fasteners, strain relief, grommets and occlusion behind chassis. Exact measured locations are to be supplied by the art lead—NO invented port coordinates.
The software mirrors this with an asset manifest; a missing or mismatched socket fails integration. Never combine isolated pretty outputs as images on top of an unrelated machine.

## 5. SHARED RUNTIME DATA — PHYSICS, SOUND AND ART DRINK FROM ONE WELL
InstrumentState: powered; x and y normalized 0..1; frequencyHz; relativePhaseRad; selectedInstrument; register; activeHarmonicRatios; activeColors; capturedStates[]; audioMuted; transportState; reducedMotion.
WaveFrame: timestamp; frequencyHz; phaseRad; complexModeCoefficients; amplitudeGrid; nodalContours; resonanceStrength; excitedPartialWeights.
CapturedState: id; timestamp; frequencyHz; phaseRad; instrument; register; harmonicRatios; actual numeric amplitudeGrid/field checksum; presentation palette/pose/motion settings. MUST support deterministic replay without canned decorations.
Controller emits InstrumentState → wave solver computes WaveFrame → audio maps SAME frequency/partials/relative phase to warm, capped voices → visual renderer maps SAME grid/partial weights to cymatic sand, height mesh and contour projection. Capturing freezes a state of this field without restricting future exploration. The surrounding mystical cognitive atlas is a consciously artistic layer, NOT purported neuroanatomy.
If a knob visibly changes something without altering the contracted physical/audio state, flag a PLACEHOLDER defect.
Sound comfort: pleasant voices (velvet keys / warm organ / glass / marimba candidates), opt-in after gesture, soft clicks within note-center proximity, short mechanical transients, smooth ramps, auto quiet on idle/tab hidden, mute, hard volume caps and zero unbounded drone. Validate with ears and duration, not screenshots.

R3: Audio can be technically coupled but aesthetically fatiguing. Require independent ear testing, gain ceiling and mute.
R4: V13 implementation is one large self-contained HTML demo and risks regressions. Refactor to independent modules before cosmetic overhaul.

R6: Drive's older design/cosmology docs include superseded lens names. Do not overwrite canon without review.
